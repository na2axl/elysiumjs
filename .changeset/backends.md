`@elysiumjs/drizzle` provides Drizzle ORM for `@elysiumjs/olympus`: database drivers (Bun SQL, postgres.js, node-postgres, Hyperdrive), models, repositories, migrations, tenancy, the moirai stores, the notification and file stores, `rulesToDrizzle()` for abilities as SQL conditions, and the `postgres` lock driver. `@elysiumjs/pino` provides the `pino` logger driver, with pretty output in development.
